# KolaSTIK

> Aplikasi desain kolase foto estetik dengan pratinjau split image presisi dan manajemen kanvas profesional berbasis Jetpack Compose.

---

## Fitur Utama KolaSTIK

- **Editor Kolase Fleksibel**: Geser, cubit (pinch-to-zoom), putar, kunci lapisan (*layers*), dan atur ketebalan border serta sudut lengkung dengan mudah.
- **Preset Template Estetik**: Berbagai pilihan template grid dan layout siap pakai untuk Instagram, Story, Feed, dan Moodboard.
- **Set Kanvas Kustom & Manual (Hingga 13500px)**: Atur dimensi piksel $W \times H$ bebas untuk kebutuhan cetak profesional maupun resolusi sosial media HD.
- **Image Splitter**: Fitur pemotong grid presisi untuk membagi satu foto menjadi beberapa bagian grid rapi untuk feed Instagram.
- **Efek & Penyesuaian Visual**: Filter foto instan, bayangan (*drop shadow*, *inner shadow*, *outer glow*), dan kalibrasi skala presisi.
- **Dukungan Mode Gelap (Dark Mode)**: Antarmuka *Charcoal Dark Studio Theme* yang elegan dan nyaman di mata.

## Cara Instalasi (Installation Guide)

### 1. Instalasi Cepat via APK (Android 7.0+)
1. Unduh file APK terbaru (`app-debug.apk`) dari direktori build project atau menu export di AI Studio.
2. Pastikan pengaturan perangkat Anda mengizinkan instalasi dari **Sumber Tidak Dikenal** (*Install from Unknown Sources*).
3. Buka file APK yang telah diunduh, lalu ketuk **Install**.
4. KolaSTIK siap digunakan di perangkat Android Anda!

### 2. Build dari Source Code (Untuk Developer)
Jika Anda ingin mengembangkan atau melakukan build sendiri dari source code:
1. Pastikan Anda memiliki **Android Studio** (versi terbaru dengan Kotlin & Jetpack Compose support) terinstal.
2. Clone repository ini atau unduh sebagai ZIP:
   ```bash
   git clone https://github.com/rachsindutama/apk_KolaSTIK.git
   ```
3. Buka folder proyek di dalam Android Studio.
4. Biarkan Gradle melakukan sinkronisasi dependensi secara otomatis.
5. Sambungkan perangkat Android Anda (dengan *USB Debugging* aktif) atau gunakan Emulator.
6. Klik tombol **Run 'app'** (`Shift + F10`) untuk mengompilasi dan menjalankan aplikasi.

## Panduan Singkat Penggunaan

1. **Halaman Utama**: Pilih template siap pakai, atur dimensi kanvas manual via tombol **Set Kanvas**, atau gunakan **Split Gambar**.
2. **Editor Kanvas**: 
   - Tambahkan foto atau frame placeholder melalui tombol **+ Tambah**.
   - Ketuk lapisan untuk memilih, geser untuk memindahkan, atau cubit dua jari untuk memperbesar/memperkecil.
   - Gunakan menu *Layer Styles* di panel bawah untuk mengatur efek bayangan, border, dan filter.
3. **Ekspor & Simpan**: Simpan proyek Anda ke database lokal atau ekspor hasil kolase beresolusi tinggi.
